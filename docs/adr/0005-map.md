# ADR 0005: Illustrated SVG map instead of a Google Maps embed
Status: accepted
**Decision:** the contact page shows a hand-made SVG map of the fictional showroom area plus a "Get directions" link (opens Google Maps in a new tab). No third-party iframe.
**Why:** no cookies/tracking, simpler CSP, matches the design, and the address is fictional anyway. A real client gets their own map link.

# ADR 0004: ThreeRT renders shipped as media; live 3D only for one chair
Status: accepted
**Decision:** hero rooms are path-traced offline with ThreeRT and shipped as AVIF/WebP stills (and optionally a short MP4/WebM loop). The ThreeRT engine never ships. The only live WebGL is (a) the hero dust canvas (2D canvas, not WebGL) and (b) a react-three-fiber chair on its product page, lazy-loaded below the fold, Draco-compressed GLB under 1.5 MB, CC0 model.
**Consequences:** photoreal look at image cost; LCP stays an image.
